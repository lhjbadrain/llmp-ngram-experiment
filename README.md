## 实测结果

环境：Windows 11、Python 3.12.3、NLTK 3.9.1，CPU。使用Witten–Bell插值平滑，共享词表及数据划分。

| 模型 | 训练秒 | 模型MiB | 验证PPL | 测试PPL |
|---|---:|---:|---:|---:|
| 2-gram | 1.1254 | 1.30 | 353.1342 | 365.4274 |
| 3-gram | 2.3019 | 4.88 | 390.4530 | 413.8898 |
| 4-gram | 2.7240 | 10.73 | 427.3889 | 454.9877 |

训练200,374词，验证20,933词，测试20,571词；按文章选取，完全相同段落去重。单次计时仅含fit及n-gram遍历；MiB为pickle文件大小；PPL包含每段一个EOS。

本轮高阶模型未改善留出集PPL。2-gram贪心出现循环；高阶输出可形成新闻措辞，却仍会偏离校园主题。12组完整输出与失败案例均保留，没有人工润色。

## 复现

需要自行取得课程提供的1998年上半年人民日报带音分词语料。本仓库不分发完整语料、处理后数据或模型。

将六个月文件放入仓库根目录的 `1998-上半年-带音/`，文件名为 `1998-01-2003版-带音.txt` 至 `1998-06-2003版-带音.txt`。

Python 3.12环境中执行：

```powershell
python -m pip install -r requirements.txt
python .\02_clean_corpus.py
python .\03_train_models.py
python .\04_generate_text.py
python .\05_evaluate_models.py
```

若依赖已安装，无需再次安装。01脚本是人工句子的教学练习，不是正式实验数据。02只读原始文件；后续各阶段自动生成所需目录。重跑会更新对应结果，训练时间会重新实测；最终汇总报告需要同步更新。

`data/cleaned/`为全量清洗正文和元数据；`data/splits/`为小规模划分；`models/`为本地训练模型。这些目录由程序生成并已被Git忽略。
